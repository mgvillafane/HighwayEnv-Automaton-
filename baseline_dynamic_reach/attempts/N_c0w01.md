# N_c0w01: no practice, c0w01

*Step 8c, trained 2026-11-18 to 2026-11-20. Seeds: 7, 10, 13. [All attempts](README.md) · [Experiment notes](../EXPERIMENT_NOTES.md)*

**Status:** Screened in Step 8c on 3 seeds; not a finalist.

## Idea

**Order N, no practice.** All three rounds are on the full task. Round 1 is success only (B0's lesson: learn to reach before any crash cost); rounds 2 and 3 use the reward under test. It asks whether practice is needed at all.

**Crash cost 0:** success only in every round, the control. Discounting alone pays for arriving early, so it predicts fast driving and many crashes.

**Progress shaping 0.1 per m** (potential-based; it cannot change the best policy). P6 had it by inheritance and it was never tested on this path.

Step 8c was the reward grid on orders N and O: crash 0 / 0.5 / 1 / 2 × progress 0 / 0.1, 3 seeds. The rule picks the simplest reward that the best one does not beat beyond noise.

## Approach

Three rounds of 2M transitions on the Windows PC, each starting from the previous round's trained policy (same seed); round 1 from fresh weights, success only.

| Run | Arm | Task | Reward | Transitions | Starts from | Trained on |
|---|---|---|---:|---:|---|---|
| 1 | `N1` | full task | +1 reach, crash 0 | 2M | fresh weights | PC |
| 2 | `N2_c0w01` | full task | +1 reach, crash 0, progress 0.002/m | 2M | `N1`'s trained policy (same seed) | PC |
| 3 | `N3_c0w01` | full task | +1 reach, crash 0, progress 0.002/m | 2M | `N2_c0w01`'s trained policy (same seed) | PC |

## Reward function

Of the last run, `N3_c0w01` (per decision, in goal units after the reward scale):

- +1 when ego reaches the slot (the episode ends)
- 0 on a crash: a crash ends the episode with nothing, like a timeout
- +0.002 × (γ·Φ(next) − Φ(now)) per decision, Φ = −(distance to the slot in m), γ = 0.99: potential-based progress, which cannot change the best policy
- 0 on a timeout (25 s) or a lost anchor

Written out: `r = 0.02 × (50·[reached] + 0.1·(0.99·Φ′ − Φ))`, where [reached] and [crash] are 1 on the decision the episode ends that way and 0 otherwise.

Earlier runs of the pipeline used:

- `N1`: +1 reach, crash 0 (`r = 0.02 × (50·[reached])`)

## Analysis

- On the screening seeds (7, 10, 13) it ranks 22 of the 26 64-64 pipelines (score +0.497; the best is O_c1w01, +0.697).
- Against success only, same order (`N3_c0w0`): -0.037 (95% interval -0.067 to -0.007, p 0.03, ahead on 0 of 3 seeds; crash rate +1.5 points).
- Against P6's reward, same order (`N3_c1w01`): -0.144 (95% interval -0.267 to -0.021, p 0.04, ahead on 0 of 3 seeds; crash rate +16.3 points).
- Against order O, same reward (`O3_c0w01`): -0.057 (95% interval -0.503 to +0.390, p 0.64, ahead on 1 of 3 seeds; crash rate +2.4 points).

Across 8c: any crash cost brings the FRONT give-up, and success only never does. The score swaps crashes for timeouts almost one for one. Nothing beat success only by the rule with 3 seeds; P6's reward scored highest in both orders.
